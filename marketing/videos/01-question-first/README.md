# 01 السؤال قبل الاسم

ريلز 9:16 (1080×1920)، قرابة دقيقتين، أول حلقة من سلسلة استراتيجيات صفّية لحسابات الأستاذ.
مبني على شكل فيديو «Teach Like a Champion» عن Technique 34 «Cold Call»: نفس البناء (مشكلة في الفصل، ثم موقف من الحياة يكشف الحل، ثم الفصل بعد الحل، ثم بطاقة الاستراتيجية)، بقصة سعودية ورسم جديد وهوية الأستاذ.

**الحالة:** النسخة الكاملة بالصوت على سطح المكتب («01 السؤال قبل الاسم.mp4»، 1:53، ‎-14 LUFS)، ومعها المسودة بدون صوت. الصوت من take2 مع السطرين 03 و11 من take1، والسبب في `script.json` (حقل `voice.picked`).

## الهوية في الفيديو

- الورق بالعاجي الفاتح `#F4F6EE`، وكل الخطوط بالحبر `#23271A`. الزيتوني لكلام المعلّم والختم، والذهبي للضوء (المصباح، اليد اللي ترتفع)، والمريمي للطالب والصح. الأحمر الصدئي (لون الخطأ في الموقع) للمصباح المرتبك ومربعات الشماغ بس.
- كل النص بخط IBM Plex Sans Arabic، والأرقام بـIBM Plex Mono، أرقام غربية فقط.
- الشعار الكامل (`alostath-logo.png`) في أول ثانية وفي الخاتمة. نسخة الهيدر مقصوصة على حدود الحروف فما تنفع للفيديو.
- لمسات سعودية: الثوب والطاقية للطلاب، الشماغ والعقال للمعلّم، البشت والغترة والدلة والفناجين للجد، الزولية بنقشة سدو، المساند، وأيام الدراسة السعودية (من الأحد للخميس، والجمعة للعيلة).
- النص والرسوم فوق أسفل 25% من الإطار، لأن واجهة تيك توك وإنستقرام تغطيها.

## قرارات تحتاج رأيك

1. **اسم الاستراتيجية:** «السؤال قبل الاسم»، وتحته «Cold Call» صغير. بدائل: «اسأل الجميع»، «المناداة المفاجئة».
2. **سطر المصدر في الخاتمة:** «مستوحاة من كتاب Teach Like a Champion لدوغ ليموف». الفكرة من الكتاب، فذكره أمانة ويحمي سمعة المؤسسة. نشيله إذا تبي.
3. **اسم السلسلة:** «استراتيجية صفّية» فوق الختم.

## الصوت (ElevenLabs)

**صوت واحد للقصة كلها**، مثل فيديوهات سيمو: راوٍ سعودي باللهجة البيضاء يغيّر نبرته لكل شخصية بأوامر ElevenLabs v4.
الأمر بالإنجليزي بين قوسين مربعين، قبل الكلام اللي يلوّنه، ويبقى شغّال لين الأمر اللي بعده (من دليل ElevenLabs الرسمي للنموذج).

| الشخصية | الأوامر |
|---|---|
| الراوي | `[warmly]` للسرد، `[softly]` للحظات الهادية، `[dramatically]` للكشف، `[slowly]` للخلاصة |
| الأستاذ فهد | `[curious]` لما يسأل، `[firmly]` لما ينادي بالاسم أول، `[warmly]` لما يطمّن، `[surprised] [laughs]` لما ينتبه |
| عبدالله | `[childlike voice]` مع `[nervous]`، و`[childlike voice] [whispers]` لـ«مو أنا» |
| الجد | `[elderly voice] [raspy]` مع `[mischievously]` للمسابقة و`[excited]` لـ«سارة!» |

والوقفات بـ«…» و`[pause]` و`[long pause]` (الانتظار قبل «سارة!» وقبل «ثانيتين»). التشكيل يوجّه النطق باللهجة، والأرقام مكتوبة بالكلام عشان تنقال بالسعودي.

**الصوت المقترح** (من مكتبة ElevenLabs، اسمعها واختر):

1. **Mansour - Saudi, Natural and Expressive**: ممثل صوت 14 سنة، لهجة بيضاء، دافي في السرد. الأقرب لأداء الطفل والجد بنفس الصوت.
2. **ALI - Saudi Arabic & English**: ينتقل بين الحماس والتأمل والفكاهة.
3. **Yousef - Warm & Trustworthy**: دافي وقريب، مصمّم للريلز والسرد.

**الإعدادات:** النموذج Eleven v4، وStability قرابة 50%، وSimilarity قرابة 75%، وStyle صفر. v4 ما فيه تحكم بالسرعة: البطء من الأوامر نفسها.

**الطريقة:** الصق النص كامل من `elevenlabs.txt` (هنا جنب هذا الملف، 1,872 حرف) في توليدة وحدة، وولّد كم نسخة واختر أحسنها.
إذا الموقع قال إن النص طويل، قسّمه نصين من سطر «لَيْلَة الأحَد…».
ما تحتاج تقسّم السطور: ارفع التسجيل كامل بأي اسم، وأنا أقسّمه سطر سطر وأوقّت كل كلمة محلياً (بدون رصيد):

```sh
cd marketing && npm install
npm run voice:split -- 01-question-first <التسجيل.mp3> --lines 01-24
```

التسجيلات مكانها `~/Movies/Al-Ostath Marketing/01-question-first/takes/`، والسطور بعد التقسيم في `lines/` جنبها.
النص المرجعي بالأرقام والأوامر في `script.json`. الصوت المنشور يحتاج باقة ElevenLabs تسمح بالاستخدام التجاري.

## لما يوصل الصوت

```sh
cd marketing
npm run voice:split -- 01-question-first <التسجيل.mp3> --lines 01-24   # 24 سطر بتوقيت كل كلمة في lines/
cd studio
npm run prep -- 01-question-first           # ينسخ السطور ويضبط مستوى كل سطر
npm run stills -- 01-question-first         # لقطة لكل مشهد للمراجعة
npm run render -- 01-question-first         # الفيديو النهائي بالصوت (‎-14 LUFS)، على سطح المكتب
```

المشاهد تتمدّد وتنكمش على طول السطور الحقيقية، وكل حركة مربوطة بكلمة في السطر، فتمشي مع الإلقاء.
التقسيم يكتب توقيت كل كلمة (`<nn>.words.json`)، والكابشن يمشي عليه كلمة بكلمة. جرّبنا الطريق كامل بتسجيل تجريبي من صوت الماك العربي: التقسيم والتوقيت والفيديو بالصوت وضبط مستواه، وكله اشتغل.
